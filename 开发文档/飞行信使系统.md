# 飞行信使系统

## 1. 功能目标

每名 PVE 玩家在选将完成后获得一只专属飞行信使。信使是玩家的功能载体，不参与战斗，拥有独立的六格原生物品栏，可拾取任何地面物品。

首版功能：

- 跟随：立即传送到绑定英雄身边。
- 范围合成：指定地面区域，将范围内可合成装备递归合成为更高等级装备。

## 2. 物编配置

| 类型 | Rawcode | 配置 |
| --- | --- | --- |
| 飞行信使 | `F0B0` | 基于普通农民 `hpea`；`Builds=""` 清空可建造建筑；`hideHeroBar=1` 隐藏左侧英雄栏条目；`AInv,A9T4,A9T5`；无攻击、无仇恨、零碰撞、522 移速。 |
| 跟随 | `A9T4` | Channel 无目标、可见；冷却 1 秒；基础命令 `channel`。 |
| 范围合成 | `A9T5` | Channel 地点目标、可见；距离 900、半径 300、冷却 3 秒；基础命令 `berserk`。 |

信使的无敌不是物编技能：单位创建后立即调用 Warcraft III 1.27 原生接口 `SetUnitInvulnerable(courier, true)`。因此命令卡没有无敌按钮，`abilList` 中也不应加入 `Avul`。运行时会短暂添加并移除 `Amrf`，仅将普通单位父级切换为飞行移动类型；该能力不会留存或显示。

配置源位于 `excelCfg/unit.xlsx` 与 `excelCfg/ability.xlsx`。修改后必须执行 `generate_lua_config.ps1`，禁止手工修改 `Build/table/*.ini` 或 `Build/map/Lua/config/*.lua`。

## 3. 运行时与背包规则

`Build/map/Lua/courier/main.lua` 在装备系统启动后创建信使，并维护以下关联：

```text
玩家 ID → 信使单位
信使单位 → 玩家 ID / 绑定英雄
```

- 每个已选英雄的玩家只创建一只信使。
- 信使是普通单位，不是英雄；`hideHeroBar=1` 隐藏左侧英雄栏中的第二个条目，但保留原生普通单位选择头像；通过 `Builds=""` 移除农民继承的建造菜单。
- 信使使用原生 `AInv` 六格物品栏，可拾取装备、材料、消耗品、任务物品等任意物品。
- 装备属性只在英雄背包内结算。装备被信使携带时，其运行时实例仍被保留，但不会给信使或英雄加属性；物品回到英雄背包后按现有拾取逻辑生效。
- 跟随只在绑定英雄存活时执行，信使传送到英雄右下侧固定偏移位置并播放闪烁特效。

## 4. 范围合成

### 4.1 材料条件

以技能目标点为中心、半径 300 的圆形范围内，只有满足以下全部条件的地面物品会参与：

- 物品拥有装备运行时实例。
- 物品配置为 `isEquipment=1` 且 `mergeable=1`。
- 装备等级为 1 至 4。

信使背包、英雄背包和未绑定运行时实例的静态物品均不参与，避免多人模式下对未知随机装备作出不安全处理。

### 4.2 合成规则

- 两件任意同等级可合成装备，生成一件随机的下一等级装备。
- 同次施法会递归处理：例如 4 件 1 级装备会生成 1 件 3 级装备。
- 5 级装备与无法配对的单件材料保留。
- 最终结果按网格排列掉落在技能目标点附近；不会自动放入信使背包。
- 随机结果统一调用既有 `equipment.generator.create_merge`，与英雄 F2 合成使用同一装备生成逻辑。

## 5. 多人同步

合成通过既有 `JiuDouEquipment` 同步通道处理。只有房主扫描地面材料并生成随机结果；其他客户端不进行本地随机。

| 消息 | 职责 |
| --- | --- |
| `BIRD_FUSION_BEGIN` | 创建批次并声明结果数量。 |
| `BIRD_FUSION_MATERIALS` | 分段传递待删除材料 UID，避免单条消息过长。 |
| `BIRD_FUSION_OUTPUT` | 传递每件结果的完整实例数据和掉落坐标。 |
| `BIRD_FUSION_END` | 校验完整性后统一删除材料并创建结果。 |

无同步接口时，单人可执行本地回退；多人仅禁用范围合成，信使、背包和跟随仍可用。

## 6. 验收清单

- 信使不显示无敌技能或攻击按钮，受到伤害不掉血。
- 信使可拾取任意物品，且六格背包满时遵循原生物品栏规则。
- 跟随会立刻传送且不影响背包物品。
- 2、4、8 件同等级地面装备按递归规则合成；最高级与余数保留。
- 信使和英雄背包内装备不会被范围合成扫描。
- 双人同时或连续施放合成后，各客户端的地面物品、装备 UID 与属性完全一致。
- 多人缺失同步接口时，范围合成不会执行且会提示本地施法者。
